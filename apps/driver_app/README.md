# Driver App (تطبيق الموصّل)

تطبيق موصّلي التوصيل بالدراجات — المرحلة 1 (راجع الخطة الكاملة في تعليقات
migration `supabase/migrations/20260822010000_drivers.sql`). سيارات
الأجرة (الكورسة) مرحلة قادمة منفصلة، غير مبنية هنا.

## قبل التشغيل على جهازك

نفس مشروع Supabase المستخدَم في تطبيق الزبون ولوحتي التاجر/الإدارة —
`lib/config/supabase_config.dart` مضبوط مسبقًا بنفس القيم، لا حاجة
لتعديله.

## التشغيل

```
cd apps/driver_app
flutter pub get
flutter run
```

## دورة عمل الموصّل

1. تسجيل حساب (رقم هاتف + كلمة سر) → إرسال بيانات (اسم + هاتف) للمراجعة.
2. الإدارة توافق على الحساب من لوحة الإدارة (`/dashboard/drivers`).
3. الموصّل يفعّل "متصل"، يستلم طلبًا جاهزًا للاستلام من قائمة "الطلبات
   المتاحة"، ثم يتقدّم بحالته حتى التسليم (نفس الخطوات الثلاث التي كانت
   الإدارة تنفّذها يدويًا سابقًا — الإدارة تحتفظ بصلاحية التجاوز دائمًا).

## الحالة الحالية

✅ تسجيل/onboarding/اعتماد، استلام وتنفيذ طلبات التوصيل، إشعارات داخل
التطبيق (شبكة الإشعارات، المرحلة 0).

مؤجَّل عمدًا: خريطة تفاعلية، تتبّع موقع في الخلفية، إشعارات Push
(Firebase)، الكورسة (سيارات الأجرة).
