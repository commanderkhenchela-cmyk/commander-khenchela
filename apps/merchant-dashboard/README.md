# لوحة تحكم التاجر — Commander Khenchela

تطبيق Next.js (TypeScript) يسمح لأصحاب المحلات بـ:

- إنشاء طلب انضمام كتاجر (يبقى `pending` حتى موافقة الإدارة)
- إدارة منتجاتهم (إضافة/تعديل/إخفاء/حذف)
- متابعة طلبات محلهم وتحديث حالتها ضمن الصلاحيات المسموحة لهم فقط
  (تأكيد/رفض الطلب، بدء التجهيز، تجهيزه للاستلام) — أي انتقال آخر
  (الاستلام من المندوب، التسليم النهائي...) من صلاحية Admin فقط،
  ويُمنع من طرف قاعدة البيانات (trigger) حتى لو حاول التاجر تجاوزه.
- تعديل بيانات المحل (الاسم، العنوان، الهاتف)

## التشغيل محليًا

```bash
npm install
cp .env.local.example .env.local   # ثم ضع القيم الحقيقية
npm run dev
```

افتح http://localhost:3000

## الأمان

- لا يُستخدم أي مفتاح سري (`service_role`) في هذا التطبيق إطلاقًا — فقط
  `publishable key` العام، ويُقرأ من متغيرات البيئة (`.env.local`، غير مرفوع
  لـ GitHub).
- كل عمليات القراءة/الكتابة تمر عبر Supabase مباشرة، محمية بـ Row Level
  Security (RLS): تاجر لا يستطيع رؤية أو تعديل أي شيء خارج محله الخاص.

## حدود معروفة (V1)

- رفع صور المنتج حاليًا عبر رابط مباشر (URL) وليس رفع ملف من الجهاز — سيُستبدل
  لاحقًا برفع حقيقي إلى Supabase Storage دون تغيير في شكل البيانات.
- التصنيفات (`categories`) تُدار من طرف Admin فقط — التاجر يختار من قائمة
  جاهزة ولا يستطيع إنشاء تصنيف جديد.
